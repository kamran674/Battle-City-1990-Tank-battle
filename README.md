## 📈 **LEARNING OUTCOMES**

This project demonstrates:

- ✅ **Comparative Pathfinding** - BFS, Greedy, A* side-by-side

- ✅ **Adversarial Search** - Minimax with real-time pruning
- ✅ **Constraint Satisfaction** - Procedural map generation
- ✅ **Agent Architecture** - Simple Reflex → Goal-Based → Model-Based → Adversarial
- ✅ **Real-time Visualization** - Live node counts and performance metrics
